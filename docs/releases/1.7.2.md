# Taskbar System Info 1.7.2

This release fixes the widget disappearing on automatically sized dock taskbars
when **Reserve space before the Start button** is enabled. It also restores the
outer `Grid` used by existing Taskbar Styler selectors.

**Release refreshed on October 13, 2026:** the source asset and `v1.7.2` tag
now include the follow-up fixes from upstream review. If you downloaded 1.7.2
before this refresh, download and compile the updated file below.

## Fixes

- Allow an auto-sized dock to grow before deciding that there is no room for
  the widget. The widget becomes visible only after the actual arranged buttons
  are checked. If the theme rejects the reservation, the original margin is
  restored without repeatedly retrying an unchanged failure.
- Restore `Grid#WindhawkTaskbarSystemInfo`. Adaptive scaling remains available
  through an inner `Viewbox`.
- Account for taskbar padding and borders consistently when measuring controls,
  placing the widget and projecting its position into the move preview.
- Retry hidden-widget placement when the parent's available width changes.
- Size dock reservations from measured adaptive layouts, including one-row
  layouts wider than the configured full-layout preference.
- Retry rejected reservations after relevant placement settings change, without
  waiting for a layout event when an external theme already removed the margin.
- Apply parent and frame width limits in content coordinates, including root
  margins and frame padding/borders, so a smaller readable layout can fit.

No new settings or migration are required. The four adaptive layouts and the
existing metric collectors remain in place.

- Prevent dock growth/shrink loops when a saved widget position is toward the
  right. Space created by the mod's own reservation is no longer treated as a
  free trailing gap, including in the move editor.
- Clear dock-only placement restrictions when switching to stretched or
  fixed-width taskbar themes, and handle switching back to a dock.

## Verification

Checked on Windows 11 26H2, build 26300.9550, with Windhawk engine 1.7.3:

- Source validation passed with version 1.7.2 and 29 settings.
- x64 build and ARM64 cross-build passed without compiler diagnostics.
- 173,469 behavioral regression checks passed.
- Isolated UI checks passed: 105 XAML cases, four layouts, five preview DPI
  scales and 200,000 generated real-font geometries. All 192,913 visible
  previews preserved placement after serialization.
- Dock tests cover cold injection, the restored Grid selector, padding/borders,
  separate tray controls, reservation toggling, rejected margins, constrained
  parents, shrinking an already expanded dock, recovery after growth, move
  coordinates and cleanup on unload. Three additional review regressions cover
  wide one-row layouts, settings-only recovery and finite frame width limits.
- Live Windows metrics smoke tests passed, including both injected engine
  failures returning the expected error code. Windows CPU thermal zones were
  unavailable on the test machine.
- Before/after dock renders and full/compact widget renders were visually checked.
- Source/documentation consistency and `git diff --check` passed.
- Follow-up XAML regressions passed for saved position fractions 0.6, 0.75 and
  0.9, move-editor candidates and transitions between dock, stretched and
  fixed-width layouts. The reported failures were reproduced before correction.
- Upstream CI passed for Windhawk 1.6.1, 1.7.3 and 2.0.0-alpha.7, along with
  PR source validation. AI review of upstream commit `9a7e2b8` found no blockers.

These UI checks use an isolated XAML host, not a live Explorer session. The
reporters' exact Frosted Glass and unpublished TaskbarTweaks configurations,
physical mixed-DPI monitor transfers and ARM64 hardware remain unverified.
Restoring the outer Grid selector does not restore every historical path to its
descendants. No GitHub Actions workflows are configured in this repository.

## Install or update

Download **taskbar-system-info.wh.cpp** from this release, replace the source
in Windhawk's mod editor, compile and enable it. Enable **Reserve space before
the Start button** if the dock needs to grow to make room for the widget.

This is a release of this repository's source. Availability through the official
Windhawk catalog depends on [upstream PR #6176](https://github.com/ramensoftware/windhawk-mods/pull/6176),
which is awaiting maintainer review at the time of this refresh. The source asset
matches that PR and this repository's main branch byte for byte.
